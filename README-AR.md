# 🏦 نظام إدارة البنك - المشروع الثالث (الإصدار الثالث) 🚀

[ **🇺🇸 Read in English** ](./README.md)

![C++](https://img.shields.io/badge/C++-Solutions-blue.svg) ![Status](https://img.shields.io/badge/Status-Completed-green.svg)

هذا هو التطوير الثاني (Extension 2) لمشروع نظام البنك. في هذا الإصدار، قمت بإضافة **نظام إدارة المستخدمين** لضبط صلاحيات الوصول إلى النظام وتأمينه.

## ✨ الإضافات الجديدة في الإصدار الثالث:
* 👥 **قائمة إدارة المستخدمين:** قائمة فرعية جديدة مخصصة لإدارة حسابات النظام.
* 🔐 **شاشة الدخول (Login):** إضافة نظام تسجيل دخول آمن يتطلب اسم مستخدم وكلمة مرور للوصول للنظام.
* 🔑 **نظام الصلاحيات:** تطبيق نظام صلاحيات متقدم يسمح للمدير بتحديد صلاحيات محددة لكل مستخدم (العرض، الإضافة، الحذف، التحديث، إلخ).
* 🛡️ **التحكم في الوصول:** إضافة منطق برمجي لمنع أي مستخدم من الوصول للعمليات التي لا يملك صلاحية لها.
* 🏗️ **عمليات CRUD الكاملة:** دعم كامل لإنشاء، قراءة، تحديث، وحذف بيانات المستخدمين.

## 🔧 التحسينات التقنية:
* 🚦 **العمليات المنطقية (Bitwise):** استخدام معاملات الـ `Bitwise` لتخزين ومعالجة الصلاحيات بشكل احترافي وفعال.
* 🏗️ **نظام الجلسة (Session):** إنشاء هيكل `CurrentUser` لتعقب حالة المستخدم الحالي وصلاحياته أثناء الجلسة.
* 📂 **تكامل الملفات:** تحسين التعامل مع ملفات البيانات لضمان دقة واستمرارية البيانات بين العملاء والمستخدمين.
